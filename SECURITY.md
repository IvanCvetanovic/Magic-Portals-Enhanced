# Security

## Reporting a vulnerability

Please report a vulnerability privately, and do not open a public issue for it.

Use a private security advisory on this repository: *Security*, then *Report a vulnerability*, once the repository is public and the maintainer has switched that on.

OWNER TO ADD: the maintainer's public contact for security reports

## What to send

* What you found and where: the file, the platform, the version.
* How to reproduce it, as short as it can be.
* What you think it allows.

Do not send game files, art, audio, levels or an APK.

## What this covers

The game, its tools (`tools/`) and its workflows (`.github/workflows/`). A flaw in the Supersonic Engine (`engine/`) is reported to that repository.

The maintainer has not published a time in which a report is answered.
