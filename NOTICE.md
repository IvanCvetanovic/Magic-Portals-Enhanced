## Third-party components in a program

A program of Magic Portals Enhanced is built from this repository and from the Supersonic Engine (`engine/`, a git submodule), which vendors the libraries below in its `third_party/` folder. The table says which components are in which program and how that was established; the licence texts follow.

How each entry was established:

* **Linked (Linux).** The link command line, the compiler's dependency log and the symbol table of a Linux program built in the Linux subsystem of the maintainer's PC with the engine commit this repository pins: the component's code, or its header, is in the program.
* **Linker flags (Linux, `--portable`).** `tools/build_linux.sh --portable` passes `-static-libstdc++ -static-libgcc` to the linker. A program built with it asks the system for four shared libraries (`libvulkan`, `libasound`, `libm`, `libc`) where the same program built without it asks for six (`libstdc++` and `libgcc_s` as well): the C++ runtime is inside it. This is read from the flags and from the list of shared libraries of one portable program, not from a symbol table.
* **Engine list.** The engine's build files (`engine/CMakeLists.txt`) and its list (`engine/THIRD_PARTY_LICENSES.md`), not a link line: no Windows, Android, macOS or iOS program was inspected for this file.
* **Data file.** A font of this repository's `game/data/fonts/`, not of the engine: the program reads it at run time to make the letters of the languages the original game's own fonts do not hold (Russian, Ukrainian, Turkish, Japanese, Arabic), and the packager puts every file of that folder, with its licence text, into an archive's data. It is not linked. No Windows, Linux, Android, macOS or iOS archive was inspected for this file; the entry is the packager's rule. Each is a subset (and, for the three Noto faces, an instance at bold) of the upstream font, which the licence calls a Modified Version, under the upstream name, none of the four faces having a Reserved Font Name its name uses.
